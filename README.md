# Pocketwise — Gen Z Financial Decision Simulator

Pocketwise is a React + Vite personal finance experience built around a ₹10,000 / 30-day challenge.

## Hackathon features
- Live remaining balance and 30-day allowance
- Safe-to-spend amount after commitments and subscriptions
- Savings goal tracking
- Monthly spending by category
- Month-end forecast based on current spending pace
- Financial health score and Low / Medium / High risk
- Upcoming commitments such as hostel and study costs
- Toggleable recurring subscriptions
- Decision Lab with what-if scenarios
- Decision Simulator showing before/after balance, allowance, forecast, savings impact, risk and health
- Unexpected-expense simulation
- Apply a simulated decision to the live transaction state
- Responsive React UI

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Important
The project ZIP should not include `node_modules`. Run `npm install` on the target machine so Vite/Rolldown optional native dependencies are installed for that operating system.
